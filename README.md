# Projet SEO — bois-de-chauffage-et-pellets.be

## Cadre
- **Modèle** : intermédiaire — comparateur/conseil qui collecte des demandes de devis et les route vers des fournisseurs partenaires. Affiliation en couche secondaire si des programmes exploitables existent.
- **Zone** : Wallonie (5 provinces), 100 % francophone
- **Site** : WordPress + Yoast + Elementor Pro sur thème Hello Elementor
- **État au 5 sept. 2026** : 2 URLs, dormant depuis le 13/09/2024. 721 impressions / 3 clics sur 16 mois.

## Diagnostic en une ligne
Domaine de 2 ans dont la position progresse passivement (73 → 44), thématique comprise par Google, demande locale déjà visible — **et 2 pages**. Le facteur limitant est le volume de contenu, pas la technique.
