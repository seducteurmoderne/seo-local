# Directions de design

Trois habillages complets d'une même page d'exemple (une page mère « Pellets »), faits le 04/10/2026. Chaque fichier s'ouvre seul dans un navigateur : polices Google, CSS et script intégrés. Le contenu est un exemple : à remplacer pour chaque site.

| Fichier | Direction | Références | Statut |
|---|---|---|---|
| `a-editorial.html` | Éditorial chaud : Source Serif 4 + Familjen Grotesk, fond papier, filets fins, sections numérotées | quel-canape.fr | prise |
| `b-cartes.html` | Cartes colorées : Bricolage Grotesque + Nunito, bordure noire et ombre décalée, pastels, bandeau CTA jaune, CTA flottant | lesmakers.fr, leswizards.com | libre |
| `c-melange.html` | Mélange : Fraunces + Figtree, vert forêt, cartes douces, accent flamme | les trois | prise |

Composants présents dans les trois : En bref, formulaire de devis en étapes, chiffres clés, courbe de prix, cartes de choix, citation, avantages/inconvénients, tableau à colonne mise en avant, note de la rédaction (B, C), checklist, bandeau CTA, liste de villes.

Pour un nouveau site : choisir une direction pas encore utilisée, puis l'adapter (couleurs, polices) au sujet.
